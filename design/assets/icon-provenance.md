# ImageStudio Studio icon

Generated 2026-09-08 using the built-in image_gen tool (logo-brand), following the approved Studio concept: charcoal and lime. No ImageStudio provider call was used.

Original: `icon-studio-original.png` (1254 × 1254 RGBA). Production: `../../resources/icon.png` (1024 × 1024 RGBA, resized with macOS sips only). Both have real alpha transparency outside the rounded tile. `../../resources/icon.ico` contains Windows sizes 16–256. Previous icon retained as `icon-before-studio.png`.

The existing Electron window/dock and electron-builder macOS/Windows configuration already consume resources/icon.png. Electron-builder converts PNG for platform packaging; the ICO is supplied as an explicit packaging resource too.

## Final generation prompt

Use case: logo-brand
Asset type: final production macOS and Windows application icon for ImageStudio, a professional AI image creation studio.
Primary request: one beautifully designed, minimal, confident icon matching a charcoal and electric-lime creative software interface.
Subject: a single bold abstract image-frame mark in pale electric lime (#d9f574), suggesting an open photographic frame and a simple image peak through clever negative space. The mark should feel distinctive, calm, geometrically disciplined, and readable at 32 pixels.
Scene/backdrop: a dark charcoal (#111213) rounded-square app-icon tile, centered and front-facing with a slim transparent margin. True transparent RGBA background outside the rounded tile, including corners; do not draw a checkerboard.
Style: polished restrained premium desktop icon, near-flat geometric design with at most subtle material shading on the charcoal tile. Crisp edges, optically centered symbol, generous internal breathing room. Large chunky simple mark, no thin detail.
Composition: square 1024x1024 canvas, rounded square tile occupies about 88% of canvas, centered lime mark occupies roughly 60% of tile.
Constraints: one icon only, no text, no letters, no mockup presentation, no multiple options, no scenery, no decorative sparkles, no stars, no rainbow gradient, no camera lens, no glossy glass, no complex 3D extrusions. Real alpha transparency around tile.
